## 2 已判否（含证据；标 ⛔ 者永久）

### 2.1 语义红线（⛔ 永久不可修）

| 项 | 为什么 |
|---|---|
| ⛔ `character()` 内联 | Gem 覆写，虚派发必须保留 |
| ⛔ 事件驱动调度（只 tick 到期物品） | 改帧内调用集合 = 换内核 |
| ⛔ 双侧循环合并 / 跳过死方 tick | 改帧内求值次序 |
| ⛔ `f32` 换 float64 / 降 tick 频率 | 直接破确定性 |
| ⛔ Godot 无头当产品运行时 | GDScript VM 更慢、打包更重 |

### 2.2 实测证伪（有数字支撑）

| 项 | 证据 |
|---|---|
| Cython 纯编译（无类型化） | 编译臂 vs 源码臂 **1.075x** |
| items 树 object 槽位化（510 模块） | `getSpeed`/`physicsTick`/`gainStacks` 全 **1.00x** |
| L2 cpdef 签名（131 处） | `hasType` 0.117 = 0.117 µs，**零增益** |
| L4 死代码消除 | `.gd` 源里 `if false:`/`if true:` **0 处** |
| B-1 装配整场复用 | deepcopy **1.889x 贵于重建** |
| A-6 `isItemAffected` 预筛 | 语义面中风险 + A-2 证明同类天花板有限 |
| **GPU 化** | 单 tick 并行宽度仅 **103**（51+52 物品）、tick 严格串行、控制流密集（分支/指针追逐/小分配）、**浮点归约会破逐位确定性**；MX130 仅 ~0.5 TFLOPS/2GB |
| **换语言 C++/Rust** | **尚无证据**——见 §3.1（不是关闭，是待测） |

### 2.3 条件关闭（触发条件写死）

| 项 | 重开条件 |
|---|---|
| nogil 并行 | ①对象图全 C 化 ②训练侧 <8 场/s 且需 ≥20 ③单场 p50 ≤150ms |
| 子解释器 | Cython 模块级全局态不支持；只在「短批次启动成本」成真痛点时试纯 py 臂 |
| `getSpeed` 整函数缓存 | 热/寒变动频繁；只有 A 类收口仍差 10% 才考虑缓存中间量 |

## 3 当前唯一路径（按顺序）

### 3.1 L3 float 面（1–2 天，**最高优先**）

**为什么是它**：这是唯一能把「换语言值不值」变成实测的问题。当前 float 面覆盖率 0，
而热路径（速度/冷却/伤害/生命/热度）全是 float。

| 关键判断 | 结论 |
|---|---|
| GDScript `float` 宽度 | **64 位** ⇒ 与 `double` 同宽，不降精度 |
| f32 从哪来 | 只在 3 模块用**显式垫片**（CoreBuff 4 / CoreCharacter 3 / CoreTimer 3 处），与槽类型无关 |
| 会不会破 f32 | **不会**：`double` 槽 + 显式 `f32(x)` ≡ 原 `object` 槽 + `f32(x)` 逐位相同 |
| 风险 | 字段被赋 `None`/`int` → 编译态 `TypeError` **立刻炸**（不静默） |
| 已抽查干净字段 | `speedScale`/`triggerTime`/`_cooldown_active`/`fatigue_next_tick`：引擎零动态赋值、源码零 `None` |

**三步**：① 放宽 `_l3_numeric_types`（加 `float`→`double`，采集面扩到 items 全树）→ 目标 ≥90 槽；
② 编译迭代 + `_L3_BLOCKLIST` 收敛到零失败；③ 三闸 + 三点微基准 + 1690。

**判读**：

- 微基准 **≥1.3x** → PyObject 常数因子真实存在，**C++ 值得评估**（可再拿 1.3–1.8x）；
- 微基准 **≈1.0x** → 84% 是算法本身，**C++ 正式关闭（有证据）**。

### 3.2 吞吐绑核（0.5 天，可与 3.1 并行）

4w 7.08 → 6w 7.01（**加核反降**）= 典型超线程争抢。用 `psutil.cpu_affinity` 绑 0/1/2/3，
目标 **≥8.5 场/s（+20%）**。零语义风险。

### 3.3 装配 20%（2–3 天）

构造 46.9 ms 占整场 20%。已否掉「整场 deepcopy 复用」，但**没分解过子项**：

| 子项 | 做法 |
|---|---|
| `Vector2` 逐物品分配 | 池化或改存 tuple |
| `chargeFrame` 每物品 4 个 `vec()` | 共享不可变实例 |
| 描述符 `_DESCR_CACHE` | 已是进程级，**先验证是否真命中** |

### 3.4 `logEvent` 残量 11.1%（1 天，可选）

`_OriginRef` / `getDepth` 可惰性化。预期 2–4% 单场。

### 3.5 吞吐其余两刀（见归档 §I-3）

T-1 chunksize 扫描（1/2/4/8/16/32 × workers 2/4/6）；T-3 短批次启动摊销（预热 + initializer 复用）。

## 4 一个必须先纠正的外部数据错误

[docs/训练路径规划.md](训练路径规划.md) §3.2 写「warm p50 = **11.8 ms** → 单核 85 场/s → 8 核 660 场/s → 1 晚 1900 万场」。

| 口径 | 文档写的 | 实测 |
|---|---|---|
| 单核 | 85 场/s | **2.6–6.5 场/s** |
| 8 核 | 660 场/s | **7.08 场/s（4w 饱和）** |
| 1 晚（8h） | 1900 万场 | **≈ 20 万场** |

**差 15–30 倍。** 该文档据此得出「本地可负担大规模真实模拟，故代理模型不必要」——
**这个结论的前提是错的 90 倍，代理模型的必要性必须重新评估。**

## 5 纪律（血泪条款）

| 纪律 | 为什么 |
|---|---|
| **账本 mtime 必须晚于代码提交** | 曾出现「声称晚于提交，实际差 1.5 小时」 |
| **编译态结论必须证明 pyd 比源新** | `build_cython` 曾「pyd 存在即跳过」，导致多轮「重编」空转 |
| **只报交错 A/B 比值，不报跨机绝对值** | `process_time` 刻度 15.6ms + 睿频抖动，p50 分辨率 ±4–10% |
| **单点微基准要加大 n** | 200k 次时跳动是刻度噪声；800k–1M 才收敛 |
| **看剖面要看总量，不只 top30 名单** | 事件计数回归就是 top1，但按名单看永远看不出 |
| **`@property` 惰性视图的计数必须 O(1)** | 每 tick 访问一次聚合视图 = 全量物化 |
| **不许改判据**（`canonical_stream`/`render_lines`/语料） | 改判据 = 作弊 |
| **不许重生成夹具** | 会造出 13 场假红 |
| **`--force` 不可与 `--skip-godot` 同用** | 假阳性 |
| **`--cases-json` 不可传全量夹具** | 脚本会写回覆盖 |
| **大文档禁止「读局部 → 整体写回」** | 曾因此截掉 45 行 |
| **判否前先确认判据测的是不是同一件事** | 「object 槽无收益」被用来否定「数值槽」，是循环论证（§H 已翻案） |

**三闸**：seed 双态（`20260923≡907`、`42≡1042`）→ REG 九场 → 60 场；1690 走里程碑。
**A 类主判据**：调用数下降 ≥80%（`--profile-out`，绕开墙钟地板）。
