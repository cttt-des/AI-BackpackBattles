# 一、核心战斗系统
================================================================================

## 1.1 冷却系统（参考 wiki/冷却）
战斗中的核心机制。所有有规律触发的物品都有冷却(CD)，冷却填满后物品激活。

### 冷却公式
- 净加速 = 总加速效果 - 总减速效果
- 净加速 > 0: 有效冷却 = 基础冷却 / (100% + 净加速)
- 净减速 > 0: 有效冷却 = 基础冷却 × (100% + 净减速)
- 冷却速度上限: 1000% (500层狂热)

### 影响冷却的因素（加法叠加）
- 星星效果/食物效果: 如笛子、食物等
- 物品自身效果: 如十字剑、圣矛
- 镶嵌宝石: 黄宝石等
- 背包: 腰包+10%冷却速度
- 狂热(Frenzy): 每层+2%冷却速度（加速）
- 冰冷(Chill): 每层-2%冷却速度（减速）

## 1.2 冷却推进/快进
- 推进效果以「固定时间」推进冷却进度，不受加速/减速影响
- 溢出可累加到下一次冷却

## 1.3 耐力系统（参考 wiki/耐力）
- 初始最大耐力: 5点
- 基础恢复速度: 1点/秒
- 武器攻击消耗耐力，不足则显示「耐力耗尽」并重新冷却
- 「攻击时：」效果即使在耐力耗尽时仍会触发

### 消耗等级
- < 1/s: 可持续
- > 1/s: 开始入不敷出
- > 1.5/s: 加速消耗
- > 2/s: 10秒内耗尽

## 1.4 命中率（参考 wiki/命中率）
- 基础命中率: 90%（大多数武器）
- 特殊武器: 西洋剑60%, 神圣长矛200%, 不愈法杖无命中率
- 幸运(Lucky): 每层+5%命中率
- 致盲(Blind): 每层-5%命中率

## 1.5 伤害公式（参考 wiki/伤害）
最终伤害 = [(基础伤害+加算伤害增加) × (100%+百分比伤害增加) 
  × 类型修正 × (暴击: 200%+暴击伤害加成) × (承受伤害: 100%+额外-减弱)] 
  - 伤害减少/格挡

### 伤害类型
- 近战(Melee): 触发尖刺、吸血
- 远程(Ranged): 不触发尖刺、吸血
- 效果(Effect): 来自宠物/非耐力物品

## 1.6 暴击
- 基础: 200%伤害
- 暴击伤害加成: 加算

# 二、Buff/Debuff 系统（层数系统）
================================================================================

## 2.1 增益 Buffs
- 幸运(Lucky): 每层+5%命中率
- 恢复(Regeneration): 每2秒每层恢复1HP
- 尖刺(Spikes): 被近战击中时每层造成1伤害（最高100%伤害量）
- 吸血(Vampirism): 近战击中时每层恢复1HP（最高100%伤害量）
- 魔法(Mana): 魔法属性物品的消耗物
- 狂热(Frenzy): 每层+2%冷却速度
- 充能(Empower): 每层+1武器伤害

## 2.2 减益 Debuffs
- 中毒(Poison): 每2秒每层1伤害
- 致盲(Blind): 每层-5%命中率
- 冰冷(Chill): 每层-2%冷却速度
- 眩晕(Stun): 暂停所有冷却

## 2.3 其他效果
- 护盾: 每层抵挡一层伤害
- 无敌: 期间不受任何伤害
- 反弹: 下一个减益转移给对手
- 不治: 治疗转化为伤害
- 净化: 移除所有减益

# 三、物品系统
================================================================================

## 3.1 物品类别
- 近战武器(Melee Weapon): 消耗耐力，可触发尖刺/吸血
- 远程武器(Ranged Weapon): 消耗耐力，不触发尖刺/吸血
- 魔法武器(Magic Weapon): 如法杖，可能不消耗耐力
- 食物(Food): 提供回复/生命/增益，一般有冷却
- 护甲(Armor): 提供防御/护盾/生命
- 盾牌(Shield): 格挡伤害，移除对手耐力
- 药水(Potion): 满足条件时消耗，有一次性效果
- 背包(Bag): 提供额外格子/各种增益
- 宝石(Gem): 嵌入槽位，提供属性
- 宠物(Pet): 效果伤害，不消耗耐力
- 工具(Tool): 打造/合成用
- 魔法书(Book/Spell): 提供法术效果

## 3.2 合成规则
- 合成条件: 配方物品在背包中相邻
- 合成时机: 下次进入商店时自动合成
- 锁定: 可锁定物品防止合成

## 3.3 稀有度
- 普通(Common)
- 魔法(Magic)  
- 稀有(Rare)
- 史诗(Epic)
- 传奇(Legendary)

================================================================================

## 5.1 回合结构
1. 商店阶段: 购买、合成、摆盘
2. 战斗阶段: 自动战斗
3. 结算: 胜/负/平

## 5.2 主客场
- 先触发玩家，再触发对手
- 多个效果随机顺序触发

## 5.3 战斗开始
- 0.00秒触发「战斗开始时：」效果
- 先玩家后对手
