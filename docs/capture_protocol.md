# 真值捕获操作单（capture_protocol）— P3 会话用

> 目标：每场历史记录对战产出一份「确定性重放输入包」：
> `output/replay/<时间戳>/` = `rng_state.txt`（最早捕获的 Util.rng.state）+
> 双方阵容 v4 + 完整事件流。供 P4 逐位对齐（`docs/deterministic_replay_workflow.md`）使用。
> 原理依据：`docs/rng_truth.md` §4（捕获必须早于首个 roll）与 §5（内存定位）。

---

## 0. 红线（先读这段）

1. **只允许在「历史记录」（BuildHistory）界面开战**：历史记录 → 选中存档条目 →
   点「对战」。绝不进入排名游戏（Ranked）、休闲游戏（Unranked/Lobbies）
   或任何在线模式。
2. 导出器是**纯外置只读**工具：不写游戏内存、不改游戏文件、不按键鼠。
   它只在你点「对战」后被动记录。
3. 游戏与导出器**都不要中途关闭**；一场战斗结束后等导出器弹「是否导出」再继续。

## 1. 准备（每次会话一次）

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | 启动游戏《Backpack Battles》，停在主菜单即可 | — |
| 2 | 启动导出器：`python combatlog_exporter.py`（或已打包的 exe） | 状态栏出现「已连接 (PID xxxx) · 等待战斗…」 |
| 3 | （可选，一次性自检）另开终端跑 `python tools/probe_rng_state.py` | 末行 `[PASS] 差分校验通过`；若 `[FAIL]` 停下来把输出发给开发，不要继续采集 |

> 顺序很重要：**先启动导出器再开战**。导出器在检测到战斗前每 0.8s 采样一次
> Util.rng，检测到战斗后自动切换 100ms 级密集轮询；战斗前最后一次采样
> （`earliest_source=pre_battle`）就是重放所需的最早 state 最优估计。

## 2. 每场对战（重复即可）

1. 游戏内打开 **历史记录** 界面。
2. 选中一条存档（对手可用「标记为对手」指定；不标记则用本地池自动选）。
3. 选好回合数 → 点 **对战**。
4. 等战斗打完（胜负判定出现），回到历史记录。
5. 导出器会弹出「⚔ 第 N 回合战斗结束 · 导出这份战斗日志吗？」：
   - 点 **导出本场**（推荐；自动导出勾选项也可事先勾上）。
   - 状态栏出现「✔ 已导出」即完成；`output/replay/` 与 `output/combat_logs/`
     各多出一个同名时间戳文件夹。
6. 换下一场（可换存档/回合），回到步骤 2。

场次建议（同工作流 P3）：先 3~5 场跑通（含黏黏龙骑士 DK 场次），再扩到 20+。

## 3. 产出物核对

每场在 `output/replay/replay_<时间戳>_R<回合>_<Win|Loss>/` 下：

| 文件 | 内容 | 用途 |
|------|------|------|
| `rng_state.txt` | `earliest_state=...`（重放唯一所需）+ 采样序列 | P4 重放的 rng 注入值 |
| `replay_*.Player.json` / `.Opponent.json` | 双方阵容（模拟器 v4 格式：物品、位置、朝向、宝石） | 重放输入面 |
| `replay_*.events.json` | 完整事件流（含 params、归属方） | 逐事件 diff 真值 |

`output/combat_logs/` 下同时间戳为人类可读渲染版（中文/英文文本 + 原始 JSON），内容一致。

**质量自检**（打开 `rng_state.txt` 看两行）：
- `earliest_source=pre_battle` → 理想：捕获早于战斗内全部 rng 消耗。
- `earliest_source=in_battle` → 可用但欠佳：战斗前采样缺失（导出器启动晚了
  或间隔刚好错过）；若重放首事件即分叉，按工作流 §3 风险表弃场重捕本场。
- `earliest_state=NONE` → 本场没有有效采样，本场作废，检查导出器是否全程在线。

## 4. 常见问题

| 现象 | 处置 |
|------|------|
| 状态栏一直「未找到游戏」 | 先开游戏再开导出器；确认窗口标题为 Backpack Battles |
| 战斗结束没弹「是否导出」 | 等几秒再试（半态自动重读）；也可点「立即导出最近战斗」 |
| 导出的阵容缺对手侧 | 对手场景已被清理（meta.lineups=player）；本场若要重放需重捕 |
| `probe_rng_state.py` 报「偏移标定命中」警告 | 正常：游戏版本更新后偏移变化，读取器自动扫描修正；把警告里的偏移回填 `config.yaml` 的 `godot:` 段可消除警告 |
| 想重玩同一场 | 直接在历史记录再点一次对战即可；每次开战都生成独立时间戳文件夹 |
