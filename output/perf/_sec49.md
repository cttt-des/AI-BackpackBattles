### 4.9 C++ 版 1690 全量确定性实测（2026-11-14）

> 用户要求「用 C++ 版跑一次 1690 全量，验证确定性」。本节是实测结果。

#### 4.9.1 结论

| 指标 | 结果 | 判读 |
|---|---|---|
| **自洽确定性**（同输入连跑两遍逐位相等） | **1690/1690 全过** | 它自身完全可复现，无随机性 |
| **winner 与神谕一致** | **1688/1690 = 99.88%** | 有 **2 场稳定分歧** |
| 事件数差 = −1（口径差） | 1660 场（98.2%） | 我方 `run()` 末尾多一条 `emit_combat_end`，**口径差非行为差** |
| 事件数差 ≠ −1 | 30 场 | 其中 8 场差异较大（−261 / −127 / −60 / −28 …） |
| 吞吐 | 206.5 s / 1690 场 = **8.2 场/s**（单线程，边跑边自校验） | 与我方单核 4.92 场/s 对比见 §4.8 |

**⚠️ 必须分清两件事**：

- **「自洽确定性」满分** —— 同一输入两次跑结果完全一致，它不是随机的。
- **「与神谕一致」不是满分** —— 有 2 场结果与神谕不同，且**连跑 3 次都一样**（稳定错，不是抖动）。

#### 4.9.2 那 2 场是什么

| case | 神谕 | C++ 版（连跑 3 次一致） |
|---|---|---|
| `run100875_r5_o100892_r5` | win=opponent, events=150 | **win=player**, events=157, ticks=962, php=1.0 |
| `run704504_r15_o704283_r15` | win=opponent, events=982 | **win=player**, events=714, ticks=801, php=97.0 |

**已排除「是我参数传错」**：用主仓 `verify_oracle` 跑这两场，判据是三方逐行一致（oracle / gd_core / py），
结果 **2/2 三方一致** ⇒ 我方 py 引擎与神谕完全吻合，**分歧出在 C++ 版一侧**。

#### 4.9.3 测量过程中踩的三个坑（都已修正，记录下来防止重复）

| 坑 | 现象 | 修正 |
|---|---|---|
| **漏传 `below_master=True`** | 首轮 1690 场 winner 一致率只有 **92.1%**（134 场失败），事件差散布 −261~+189 | 账本 `convention` 里写的 `below_master: false` 是**陈旧记载**；`native_sim_cpp/tools/check_three_gates.py:291` 的注释明确：`verify_oracle` 的 py 腿对两个语料都硬编码 `True`，且有四臂归因实验（`_attrib_expand.py`）实证。补上后 → **99.88%** |
| **直接传 cases 的 player/opponent** | py 与 C++ 双方都跑出 `ticks=1532`（超时上限）、`events=14` | cases 里的 side dict **不是**引擎可直用的 lineup；`verify_oracle` 需夹具（`gem_lens`/`activation_order`/`rng_state`/`p_stats` 等十几项 case 级覆盖）。→ 判定「C++ 版缺陷」必须走 `verify_oracle`，不能自己拼输入 |
| **用自带 `test_parity.py` 对拍** | 20/20 全红、ticks 差上百 | 该 bundle 是 0.5.0 抽出的，它的 Python 参考腿（`run_gd_case`）与本仓库版本不匹配，且缺 `backpack_ai`/`simulator.godot_order`。**它的对拍结论对本仓库无效**，但它的**判据口径**（对齐神谕）可用 |

#### 4.9.4 对我方的三条启示

| 序 | 启示 | 依据 |
|---|---|---|
| **N5** | **C++ 重写不能保证语义 100% 等价**：它 99.88%，我方 1690/1690。做 C 化改造时，**逐位对齐闸必须每一批都跑**，不能"一次性重写再验收" | 2 场稳定分歧 |
| **N6** | **口径参数（`below_master` 等）比实现更易错**：我漏传一个 bool，一致率从 99.88% 掉到 92.1% | 首轮 134 场假失败 |
| **N7** | **事件数差 −1 是已知口径差**，可作为「是否同局」的快速判据：1660/1690 场命中 | 98.2% 命中 |

#### 4.9.5 一句话

> C++ 版**自洽确定性满分**（1690/1690 可复现），但**与神谕差 2 场**（99.88%），且这 2 场稳定可复现、我方判定为对。
> ⇒ 「换 C++ 更确定」这个假设**不成立**；它的价值在速度（§4.8），不在确定性。
