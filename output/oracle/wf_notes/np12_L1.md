## 3. run1022_r18 深挖（本轮唯一 gd 缺笔的场）

### 3.1 三方事实
- probe（新进程，`ORACLE_FIGHTS_ROOT=output/oracle/probe/np12_L1_run1022_r18
  ORACLE_ONLY_CASES=run1022_r18`）= 3915 事件；gd 腿 3910；语料 3905。
- 共享前缀至 idx1385（t=13.0）三方逐事件全同；idx1386：probe 与语料同为
  `109 Banner TO -1 @13.0333 tgt=0`，gd 无（gd 下一 tgt=0 TO 在 @14.4）。
- 语料（批量语境）与 probe（单场语境）在此笔上**一致** ⇒ 不是跨场语境差，是 oracle 两语境共有、
  gd 独缺的一笔。

### 3.2 批次列表模拟（oracle Buff.gd 语义复刻，全源输入）
输入=共享前缀内全部 `type=109, target=0` 事件（任意 origin；GAIN 按 duration 入临时批、
duration=None 入 permanentStacks；TO=按 nextTemporaryTimeout 弹；非 TO 负值=先吃永久后按
timeout 最远者拆临时批；REARM=最早 timeout−now，delay≤0.01 递归）。校验：
- 模拟复现**全部**可见 TO 弹（15/15，含 @5.5167/-7 到 @12.8/-1）；
- 模拟 @12.8 弹前 tos 与 gd BSCHED 行 10494 **逐批全同**（[12.8x1,14.3833x1,14.75x1,13.85x7,
  16.1667x1,16.2667x1,14.8167x7,16.8167x1,17.4833x1,17.4833x1]），POP idx=0、REARM
  delay=1.05 next=2 与 gd 行 10495/10499/10500 全同（output/oracle/probe/np12_L1_gd1022_bsched/
  run1022_r18/rng_trace.txt，该 trace 与电池 gd 腿 events 3910/3910 零分歧）；
- ⇒ **gd 的计时器/批次行为 == oracle Buff.gd 共享语义**；模拟在 idx1385 后给出下一弹
  @13.85（LG -7），**给不出 oracle 实际的 @13.0333 一弹**。

### 3.3 oracle @13.0333 一弹的来源（隐形状态，证据闭环）
- oracle 的 @13.0333 弹真实存在：ORACLE_DEBUG 仪器（output/oracle/probe/np12_L1_1022_dbg/
  stdout_debug.txt）中盲批计时器（/root/Main/Player/Character/@@1569）在真实场（U.time−47.817
  == combatTime，恒等映射已核）于 U.time 60.617(→12.8) 与 **60.85(→13.0333)** 连续两发，
  随后 61.667(→13.85)。[@@1569 身份：bt-resync 行 eng=5.0000（盲 dur）与 t=2.5 eng=3.0
  （LG RESCH）锚定；U.time 为进程累计，暖场≈47.8s]
- 无 [bt-resync]（0 行）∈(12.8,13.05) ⇒ 非外部 start/changeTimer 重同步（Util.changeTimer
  调用点仅 Character.gd:1048 invulnerability 与 Combat.gd:921-924 combatTimer/animationTimer，
  不触盲批）。
- 唯一自洽解释：**oracle 的 Shelly -5（事件 idx827 @9.2833，tgt=0）被永久栈全额吸收
  （5 perm + 0 临时），未拆任何临时批**——而 gd 拆了 1（BSCHED 行 6823：`CLEANSE amt=1
  farthest=13.016667x1`，即 @8.0 idx698 那批被移除；4 perm+1 temp，与可见永久盲收益 4 笔
  吻合：Rainbow Orb+1@0、Skull Badge+1×3@1.25/2.4833/4.6833）。oracle 若多 1 层隐形永久
  （null-item GAIN 不发事件，Buff.gd:177 `if item:` 门）或该批 timeout 读数+1 tick
  （13.0167→13.0333），则其 @12.8 REARM earliest=13.0333、delay=0.2333 ⇒ @13.0333 弹该批
  （-1 Banner ✓）→ REARM 13.85 → @13.85 LG -7 ✓——**oracle 全序列复现**。
- 该隐形状态（1 层永久盲 / 1 tick 批读数差）不存在于任何事件流 ⇒ **gd 的逐场输入无法复原**
  ⇒ gd 侧不可修（修了必然破坏 gd↔oracle-fresh 全等与 REG）。
