## 重构：外置模式 + Web GUI 控制台

### 变更原因
用户要求：(1) 不修改游戏文件，改为纯外置程序；(2) 做一个控制台GUI方便控制

### 核心模块重建
- `core/memory_reader.py` — Windows进程内存读取器（ReadProcessMemory封装）
  - 支持 int32/float/int64/string 读取
  - 内存区域枚举、int32/float 扫描
  - GameValueLocator: 自动定位金币/HP/回合数地址
  - MemoryGameState: 每帧轮询更新
- `core/window_manager.py` — 游戏窗口管理 + UI坐标计算
  - WindowManager: FindWindow → 获取位置/大小/PID
  - GameLayout: 比例坐标→屏幕坐标转换（grid_cell/shop_slot/storage_box/sell_box等）
- `core/actions.py` — 重写为基于 pyautogui 的坐标操作
  - buy_item/place_item/sell_from_grid/start_combat/reroll_shop/rotate_item
  - execute_plan: 批量执行操作计划
  - emergency_stop: 紧急停止
- `core/state_tracker.py` — 独立状态模型（不依赖内存读取）
  - BackpackGrid: 7×9网格管理（can_place/place/remove/find_empty_spot）
  - GameStateTracker: 追踪金币/HP/回合/物品/操作历史
  - 与内存读取双向同步

### Web 控制台
- `dashboard/server.py` — Flask + SocketIO 服务器
  - REST API: /api/status, /api/windows, /api/config
  - SocketIO事件: init_bot/start/pause/stop/step/emergency_stop
  - 实时状态推送（0.5秒间隔）
- `dashboard/templates/index.html` — 控制台HTML
- `dashboard/static/css/dashboard.css` — 深色主题样式（背包网格可视化）
- `dashboard/static/js/dashboard.js` — 前端SocketIO交互
  - 实时背包9×7网格渲染（颜色区分武器/护甲/食物/药水类别）
  - 日志面板（200条上限，自动滚动）
  - 键盘快捷键（Space暂停/继续，Esc紧急停止）

### 架构变更
旧: 游戏 ← PCK注入Bridge → TCP → Python Bot
新: 游戏 ← 进程内存读取 + pyautogui输入 → Python Bot ← WebSocket → Web GUI

### 启动方式
```bash
# Web 控制台（推荐）
python dashboard/server.py

# 命令行模式
python -m core.bot --verbose
```

## 打包为一键启动 exe (2026-07-26)

### 交付物
- `launcher.py` — exe 入口，启动 Web 控制台并自动打开浏览器；含 Windows 控制台 UTF-8 修复（ctypes SetConsoleOutputCP(65001) + stdout.reconfigure），中文显示正常
- `build_exe.py` — 一键构建脚本（PyInstaller --onefile --console），每次改代码后运行即可刷新 exe
- `core/paths.py` — 统一 base_dir 解析（区分 frozen exe 和 dev 模式）
- 产物: `dist/BackpackAI.exe` (~15.7 MB)，旁边附可编辑的 config.yaml

### 关键坑与修复
- **safe-delete/回收站失效**：此 D: 盘的 trash 操作会 FAIL_CLOSED，导致 PyInstaller 覆盖旧 exe 时 os.remove 报错、构建失败。
  - 修复：build_exe.py 新增 `_clear_old_exe()`，构建前先尝试 os.remove，失败则把旧 exe 重命名归档到 `dist/_old_builds/`，保证每次重建都不阻塞。
  - 通用规律：本工作区删除文件优先用 mv 重命名，不要依赖 rm/回收站。
- emoji 写入文件易触发异常，launcher/build 脚本改为纯 ASCII 输出。

### 冒烟测试
- exe 启动 → HTTP 200，控制台标题「背包乱斗 AI 控制台」中文正常，CSS/JS/SocketIO 加载成功。

### 启动方式（最终）
双击 `dist/BackpackAI.exe` 即可，自动打开 http://127.0.0.1:8080
