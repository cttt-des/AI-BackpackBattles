### 密钥获取（最终方案：运行时 hook）
- **真实密钥**：`8671424952511006d39f4c9e918f821391e2b06a80d946d693fb8757154ce849`（已存 tools/script_key.txt）
- 密钥在 exe 中是**混淆存储**的，运行时由 GDEC 解密函数重建为明文 32 字节。
- KeyDot 提取的 `8671...5292...` 是混淆 blob，**不是**真实密钥（第 5/12 字节不同：92→51、5e→91）。
- **获取方法**：DLL 注入 hook 游戏内 `FileAccessEncrypted` 的 GDEC 处理函数入口（RVA 0x1621820，含 "GDEC" magic 比较的那个函数），入口处抓寄存器参数 → 扫描 this 对象偏移 0x20 处的 Vector<uint8_t> → 得密钥。实现：`C:/tmp/bb/grabkey.c`（绝对跳转 hook：`mov rax,imm64; jmp rax` 12 字节，避免 rel32 溢出）+ `inject_cap.c`（CREATE_SUSPENDED 创建→先注入→等 hook 装好→ResumeThread）。
- 踩坑：hook 0x16223b0（错误位置，是错误处理代码非入口）→ calls=0 抓不到；rel32 jmp 会因 handler 与 target 距离超 2GB 溢出崩溃 → 必须用绝对跳转。
- 本机 exe 验证锚点（版本漂移会变）：GDEC magic 比较在 RVA 0x1621cca 附近；GDEC 处理函数入口 RVA 0x1621820。

### GDEC 容器格式（decrypt_gde.py 已确认）
```
[4 "GDEC"][4 version=1][16 MD5(plaintext)][8 LE plain_len][AES-256-ECB 密文]
```
- **AES-256-ECB，无 IV！** 密文从 offset 32 开始（16 对齐），解密后明文以 `GDSC\x0d\x00\x00\x00` 开头，MD5 校验。
- （之前一直误用 CBC+IV 假设，导致密钥验证失败——格式错了。）

## 🐞 战斗开始时间戳错误修复（用户反馈）
- **问题**：日志首行时间戳为 `2.50` 而非 `0.00`。
- **根因**：`combat.py` 给每个事件 `now = COMBAT_DELAY(2.5) + self.combat_time`。但原版 `CombatTimer.gd.getTimeStamp()` 返回 `combatTime`（在 `activateItems`→`combatTimer.start()` 时仍为 `0.0`，因为 `_physics_process` 在那之后才启动累加），**COMBAT_DELAY 只是回合切换倒计时，不计入日志时间戳**。
- **修复**：所有 `now` 改为 `self.combat_time`（从 0 起）；`combat_start(0.0)`；`_record_hp`/`summary` 的 time 同理去掉偏移；`events.py` `current_time` 初值 `0.0`。已验证首行 `0.00:  Gained 4 Spikes...`。

- **② 网格邻接 / 联动 / 宝石未建模**：lineup JSON 含 `row/col/rotation/container/contents/gems`，但 `simulator/` 无 adjacency/neighbor/linkage 逻辑（grep 空）；相邻加成、物品联动、镶嵌宝石效果均未实现。
- **③ 无真值 oracle**：无办法对给定阵容跑真实游戏并导出其战斗日志做自动比对，所有校验靠人工目测，难证 100% 对齐。
- **④ RNG/触发顺序确定性**：原版用 Godot 全局 RNG 做 `items.shuffle()` 与伤害/暴击掷骰；本模拟器用 Python `random` + 派生种子，RNG 流与调用顺序不同 → 同种子结果会分叉；tick 量化(1/60s)在多个冷却同时到期时也可能翻转触发顺序。
- **⑤ 战斗公式逐项待核对**：block 减伤/spikes 反弹/vampirism 比例/crit 倍率/buff 堆叠上限/持续时间刷新规则等藏在 `Character.gd`/`Combat.gd`，需逐条转录并单测（用户原则：拒绝臆测）。
- **⑥ 特殊机制缺口**：reincarnation、无敌时序、lucky、mana/empower/heat 互作、职业被动（仅 7 角色，但如 Reaper 击杀吸血等未建模）、bag/container 内容物修正等。
