### 关键踩坑（GDScript 3.x，后续复用时直接照抄结论）
- `log` 是内置函数 → 成员名必须叫 `combat_log`；`seed` 也是内置 → 形参不能叫 `seed`。
- class_name 互相引用（含自引用）报 `cyclic dependency`：`CoreItemData.fromDict` 要改实例工厂 `var o = self`。
- `round()/ceil()` 返回 float → 声明 `-> int` 的函数不能直接 return；`(int-int)*5` 是 int → 声明 `-> float` 会炸。
  **修法是去掉原版本就没有的返回类型标注，而不是加强转**（忠实优先）。
- 用 `--script X.gd`（`extends SceneTree` + `_init`）才能无头跑并正常退出；`extends Node` 主场景会挂起。
- Godot 每个脚本只报**第一个** parse error → 用 `ParseAll.gd` 逐文件 load 才能一轮拿全。
- Godot 在 Windows 控制台按 CP936 输出中文，写文件走 UTF-8 → 读子进程输出要 utf-8→cp936 回退。
- **并行 Edit 同一文件会丢改动**（本次 `snapped`→`stepify` 与 `getBuffAccuracyMod` 各丢一次），改同文件必须串行。
