## 注入方案（解决 README 三大问题）

用户允许编写程序注入游戏进程。参考 bpb_enhance 的 PCK 补丁方案，实现桥接注入。

### 改动清单

**新增文件：**
- `bridge/inject.py` — PCK 注入器（自动查找游戏、解析/重建 PCK、修改 Main.tscn、注入 bridge.gd）
- `core/bridge_client.py` — Python 端桥接 TCP 客户端

**修改文件：**
- `bridge/bridge.gd` — 增强：添加 `get_item_details`、`get_shop_offers`、`get_backpack_items_full`、`get_connector_data`、`get_item_price`、`get_full_game_state` 命令
- `core/item_reader.py` — 添加桥接模式：ItemReader 支持 `use_bridge=True`，读取物品时尝试通过桥接 TCP 补充价格/联动数据

### 注入结果
- PCK: `D:\steam\steamapps\common\Backpack Battles\BackpackBattles.pck`
- 文件数: 9377 → 9378（新增 res://bpb_ai_bridge.gd）
- Core/Main.tscn 已修改为加载 BPABridge 节点
- 桥接 TCP 服务端口: 19527
- 备份: `.bak` 文件存在

### 解决 README 三个问题的方案
1. **物品联动读取和显示** — 桥接 GDScript 在游戏进程内运行，可通过 `get_connector_data` / `get_item_details` 直接读取运行时联结器数据
2. **关闭窗口后进程不结束** — 桥接模式下从 TCP 读取数据替代主线程阻塞的 ReadProcessMemory，已有看门狗应能正常工作
3. **商店物品价格读取** — 桥接通过 `get_shop_offers` 直接访问物品脚本的 `price` 属性成员

### 使用方式
```bash
# 首次注入（已执行）
python -m bridge.inject inject

# 检查状态
python -m bridge.inject status

# 恢复原版
python -m bridge.inject restore
```
