# 2026-08-22 工作日志

## 修复 BackpackAI.exe 运行时 ModuleNotFoundError: No module named 'yaml'
- 现象：双击 dist/BackpackAI.exe 启动即崩，Traceback 指向 `core/bot.py` 的 `import yaml`。
- 根因（两层）：
  1. 构建用的系统 Python 3.14.5 未装 PyYAML（之前为 tkinter 改用的解释器只带 Tcl/Tk）。`build_exe.py` 里 `--hidden-import yaml` 只能“声明”，模块不在环境里就打不进 exe。
  2. **隐蔽坑**：`build_exe.py` 的 WORK_DIR 是固定目录 `Temp/bb_backpackai_build`，PyInstaller 跨构建复用其中缓存的 Analysis .toc —— 该缓存是上一轮“yaml 未装”时生成的，导致装上 PyYAML 后重建仍缺失 yaml。改用 `launcher.py` 在相同环境做最小复现构建（全新 work dir）能正常打进 yaml（17 个模块），坐实是缓存问题。
- 修复：
  - 在系统 Python 3.14.5 安装 `pyyaml`（6.0.3）。
  - `build_exe.py`：`WORK_DIR` 改为每次构建唯一的 `bb_backpackai_build_<毫秒时间戳>`（放 Temp 同时绕过 safe-delete shim 的 base_library.zip 清理失败）。
  - `build_exe.py`：新增 `_ensure_runtime_deps()`，构建前硬性校验 `yaml/tkinter/PIL/pyautogui` 可导入，缺失则清晰报错退出（exit 2），杜绝“环境缺依赖却产出坏 exe”。
- 验证：用 PyInstaller 的 `CArchiveReader.open_embedded_archive("PYZ.pyz")` 读取 exe 内 PYZ，确认 17 个 `yaml.*` 模块已打包；同环境 `import core / gui.app / core.bot` 均通过。重建 dist/BackpackAI.exe（120.2 MB）。
- 经验：**PyInstaller onefile 重建后某模块仍缺失 → 先查 (a) 构建 Python 是否装该包，(b) 是否 `--hidden-import`，(c) 是否复用了带陈旧 Analysis 缓存的固定 work 目录（最隐蔽）。** 用 `CArchiveReader + ZlibArchiveReader` 可直接校验 exe 内是否真的打进了目标模块。
